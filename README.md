# 🛒 Fresh Mart - Grocery E-Commerce Website

A full-stack grocery e-commerce web application built with **React.js, Node.js, Express.js and MongoDB**.

## 🌐 Live Demo

👉 https://ecommerce-website-seven-cyan.vercel.app/

## ✨ Features

- 🔐 User Login & Signup
- 📧 OTP Verification
- 🔑 Forgot Password & Reset Password
- 🔎 Product Search
- 🥦 Product Categories
- 🛒 Shopping Cart
- 📍 Location Selection
- 💳 Razorpay Payment Integration
- 📱 Responsive Design
- ⚡ Lazy Loading for Product Images

## 📂 Project Overview

Fresh Mart is a grocery shopping platform where users can browse products, search for products, select categories, add items to the cart, select a delivery location and proceed to payment.

The project also includes user authentication and password recovery functionality through OTP verification.

## 🔐 Authentication

- User registration
- User login
- OTP verification
- Forgot password
- Password reset
- One-hour login session expiry

## 💳 Payment

Razorpay payment checkout has been integrated for the grocery ordering flow.
